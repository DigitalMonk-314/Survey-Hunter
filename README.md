# Survey Hunter

Персональный Telegram-агрегатор объявлений об исследованиях и опросах.

## Цель проекта

Автоматически отслеживать заданные публичные Telegram-каналы, находить объявления о наборе участников на исследования, извлекать основные условия участия и отправлять пользователю подходящие предложения.

## Основные возможности

- Мониторинг заданных публичных Telegram-каналов.
- Поиск объявлений об опросах и исследованиях.
- Извлечение ссылок из текста.
- Определение города, возраста, оплаты, длительности и темы исследования.
- Фильтрация и оценка объявлений по профилю пользователя.
- Защита от повторной обработки одинаковых объявлений.
- Сохранение объявлений в SQLite.
- Отправка подходящих предложений через Telegram-бота.
- Сбор обратной связи от пользователя.

## Технологии

- Python 3.11+
- httpx + BeautifulSoup — асинхронный парсинг веб-превью Telegram-каналов (с v0.9.0, ранее использовался Telethon).
- aiogram 3 — Telegram-бот для уведомлений и команд.
- SQLite и aiosqlite — хранение данных.
- PyYAML — настройки и профиль пользователя.
- pytest — тестирование.

## Конфигурация

Настройки приложения и профиль пользователя хранятся отдельно от исходного кода. Секреты, включая токены и данные авторизации Telegram, не должны попадать в Git или публиковаться.

## Принцип разработки

Проект реализуется поэтапно. Каждый этап должен иметь понятный результат и проверяться до перехода к следующему. Реализация должна соответствовать архитектуре и техническим решениям из документации.

## Текущий статус

Реализация MVP (v0.9.0). Производится переход с Telethon на HTTP-парсинг публичных каналов. Код в папке `app/` будет обновлён в v0.10.0.
