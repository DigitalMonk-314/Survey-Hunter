# Survey Hunter

Персональный Telegram-агрегатор объявлений об исследованиях и опросах.

## Цель проекта

Автоматически отслеживать заданные Telegram-каналы, находить объявления о наборе участников на исследования, извлекать основные условия участия и отправлять пользователю подходящие предложения.

## Основные возможности

- Мониторинг заданных Telegram-каналов.
- Поиск объявлений об опросах и исследованиях.
- Извлечение ссылок из текста и кнопок сообщений.
- Определение города, возраста, оплаты, длительности и темы исследования.
- Фильтрация и оценка объявлений по профилю пользователя.
- Защита от повторной обработки одинаковых объявлений.
- Сохранение объявлений в SQLite.
- Отправка подходящих предложений через Telegram-бота.
- Сбор обратной связи от пользователя.

## Технологии

- Python 3.11+
- Telethon — чтение сообщений Telegram-каналов.
- aiogram 3 — Telegram-бот для уведомлений и команд.
- SQLite и aiosqlite — хранение данных.
- PyYAML — настройки и профиль пользователя.
- pytest — тестирование.
